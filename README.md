# Site de escola de idiomas

Projeto de estudo de HTML e CSS desenvolvido durante o aprendizado com a Alura. A proposta é montar um site institucional de uma escola de idiomas, com navegação entre páginas.

## Páginas e tecnologias

- `index.html`: apresentação da escola.
- `about.html`: conteúdo sobre a instituição.
- `blog.html`: página de conteúdo.
- `style.css`: estilos do projeto.

As páginas utilizam HTML e CSS, sem dependências de instalação.

## Como visualizar

```bash
git clone https://github.com/JoaoAlencar00/site_university.git
cd site_university
```

Abra `index.html` em um navegador para consultar a estrutura e navegar entre as páginas.

## Estado atual

Os HTMLs apontam para `./styles/style.css` e `./assets/`, enquanto os estilos e as imagens estão na raiz do repositório. Por isso, a versão atual precisa ajustar esses caminhos para carregar a apresentação visual completa.

## Aprendizados

Estrutura de páginas, links de navegação, organização de conteúdo e estilização de um site institucional.

Este é um exercício educacional; os nomes, textos e referências visuais presentes nas páginas fazem parte do material de estudo.
